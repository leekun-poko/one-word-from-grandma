The entry is exactly one word: the word a grandma would text about AI. She means ChatGPT — she just types it the way she hears it, one letter bravely misplaced, and sends it with total confidence: **chatgbt**. The program writes that single word, and nothing else, to the entry file.

## Run it

```sh
python3 main.py
```
